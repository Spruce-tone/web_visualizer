# 공개 데이터 보정 (선택 사항)

패널의 **점수 기준 → 공개 데이터 보정** 은 이 폴더에 `weights.json` 이 있을 때만 고를 수 있습니다. 없으면 기본 규칙만 씁니다.

## 만드는 법
1. KAIST·MPI-SP 연구팀의 공개 데이터(https://doi.org/10.5281/zenodo.20257085)를 내려받습니다. 용량이 큽니다.
2. 데이터의 열 이름을 확인하고 실행합니다.
   ```bash
   npm run calibrate -- --data <파일.jsonl 또는 .csv> --user <작성자 열> --text <본문 열> --likes <좋아요 열> --label <의심 여부 열> --limit 2000000
   ```
3. `calibration/weights.json`(가중치)과 `calibration/report.json`(AUC, 정밀도, 오탐률)이 만들어집니다. 커밋하면 릴리스 zip에 포함됩니다.

## 범위와 한계
- 보정하는 것은 **작성자 점수**의 가중치 4개(자기 복제, 다른 사람과 같은 문장, 다작, 좋아요 감점)뿐입니다. 어조·주장·대상은 어느 프로필에도 없습니다.
- 묶음 점수(복붙 의심)는 묶음 단위 정답이 없어 보정하지 않습니다.
- 그 데이터는 네이버 뉴스 댓글이고 라벨은 모델이 예측한 "의심"입니다. YouTube에 그대로 맞는다는 보장은 없으므로 기본값이 아니라 선택 사항으로 둡니다.
- 데이터 파일은 저장소와 확장 프로그램에 넣지 않습니다.
