# 의심 신호 판별 방식과 참고 연구

> 모든 신호는 **판정이 아니라 사람이 검토할 우선순위**입니다. 근거(공통 표현, 작성자 수, 시간대)를 함께 보여 사람이 판단합니다.

## 1. 복붙·템플릿 의심 신호 (`lib/signals.js` → `clusterSignals`, 기준 `rule-v2`)

1. **문구 임베딩**: 댓글을 정규화(소문자, 문장부호·URL 제거)한 뒤 문자 2·3-gram과 단어를 feature hashing(256차원) → TF-IDF → L2 정규화. 뜻이 아니라 **글자가 얼마나 겹치는지**를 봅니다.
2. **묶기**: 댓글마다 유사도 상위 8개 이웃을 찾고, 기준(기본 0.6) 이상인 이웃끼리 이어 덩어리를 만듭니다.
3. **자연스러운 반복 거르기** (점수를 내지 않음): 짧은 반응, 흔한 인사·응원, 영상 제목·설명 인용, 타임스탬프 댓글, 참여 요청 영상, **사슬 묶음**(이웃끼리만 닮아 이어졌고 묶음 전체 평균 유사도가 0.6 미만 — 서로 다른 짧은 응원·인사가 이어진 것. 0.10.0부터).
4. **판단 보류**: 묶음 댓글이 3개 미만.
5. **점수(0~100)**: 아래 항목의 합. 50점 이상이면 지도에 표시.

| 항목 | 점수 |
|---|---|
| 묶음 평균 유사도 ≥ 0.75 (거의 같은 문구) / ≥ 0.6 (비슷한 표현). **묶음 안 모든 쌍**의 평균(70개 넘으면 고르게 뽑은 2,400쌍) | +35 / +15 |
| 서로 다른 작성자 수 (2명 이상) | +6 × 명 (최대 30) |
| 같은 작성자가 반복 작성 | +10 |
| 영상 전체 댓글의 10% 이하만 달린 시간 구간에 묶음 전체가 몰림 (분·시간 단위 시각이 80% 이상일 때만) | +20 |
| 30자 이상 긴 문장인데도 겹침 | +5 |

0.9.3까지는 평균 유사도를 이어진 쌍(0.6 이상)만으로 쟀습니다. 그러면 사슬 묶음도 0.8~0.9가 나와, 검증 세트(2026-11-25, 30개 영상)에서 뮤직비디오의 짧은 응원 225개가 한 묶음으로 점수를 받았습니다(music 평균 의심 비율 15.0%, 통과 기준 5%). 모든 쌍으로 재면 그 묶음은 0.30이었고, 고친 뒤 분류별 평균은 music 1.5%, politics-a·b 0.5%·0.5%, news 0.1%, game 0.5%, daily 2.0%입니다. 남은 묶음은 같은 글 그대로 복사, 광고 링크 글, 스트리밍 독려 문구처럼 실제 반복입니다(`docs/validation.md`).

근거로 **공통 표현**(묶음 댓글의 60% 이상이 같이 쓰는 연속 단어 1~8개)을 함께 보여줍니다. 어조·주장·대상은 항목에 없습니다.

## 2. 작성자 신호 (`lib/authors.js`, 논문 4장의 행동 특징을 영상 단위로 옮김)

댓글 3개 이상 쓴 작성자만 평가합니다.

| 항목 | 점수 |
|---|---|
| 자기 복제 비율 (1 − 고유 댓글 수 ÷ 댓글 수, 10자 이상만) | × 40 |
| 다른 작성자와 문구가 겹치는 댓글 비율 | × 30 |
| 이 영상 작성자 중 상위 5% 다작 (5개 이상) | +15 |
| 평균 좋아요가 상위 25% | −15 (논문: 평균 좋아요가 높을수록 일반 사용자 쪽) |

참고로만 보여주는 것(점수 없음): 서로 답글을 주고받은 상대 수, 작성 기간, 자동 생성형 핸들.
**작성자 지도**는 위 행동 특징을 표준화한 벡터로 비슷한 작성자끼리 이은 그림입니다.

## 2-1. 다른 패턴 (`lib/patterns.js`)
- **같은 주장, 다른 표현**: 의미 유사도가 그 영상 상위 10% 수준이고 문구 유사도는 0.45 미만, 작성자 3명 이상, 3개 이상. (논문 부록 D: 글자를 거의 다 바꿔도 의미로는 잡힌다)
- **한 댓글에 비슷한 답글이 몰림**: 수집된 답글 5개 이상·작성자 4명 이상인 스레드에서 답글 절반 이상이 같은 묶음.
- **같은 시간대에 함께 쓴 작성자**: 분·시간 단위 시각이 있는 댓글만으로, 같은 1시간 구간에 3번 이상 함께 나타난 작성자. 시각이 거칠면 보류.
- **영상 간 교차**: 창을 연 동안 분석한 영상들에 함께 나타난 작성자 (메모리에만).

## 2-2. 평가 표현 (`lib/tone.js`) — 설명용
비난·칭찬 일반 낱말의 개수로 "비난 표현 / 칭찬 표현 / 섞임(불확실) / 없음"을 나누고, 표현별 댓글 수·좋아요 중앙값·좋아요 상위 10% 안 비율을 보여줍니다. **점수와 지도 배치에는 쓰지 않습니다.**

## 2-3. 점수 기준 프로필 (`lib/weights.js`)
- 기본 규칙(`rule-v2`): 위 표.
- 공개 데이터 보정(선택): `calibration/README.md`. 작성자 항목 4개만 보정하며, 설치돼 있을 때만 패널에서 고를 수 있습니다.

## 3. 참고 연구

**KAIST·막스플랑크 연구팀, USENIX Security 2026** — 네이버 뉴스 댓글 약 1억 1천만 건(2006~2025)을 분석해 해외 연계가 의심되는 계정 약 2만 4천 개를 찾은 설명 가능한 AI 연구 ([AI타임스 기사](https://www.aitimes.kr/news/articleView.html?idxno=41406), [arXiv 2606.22785](https://arxiv.org/pdf/2606.22785)).

USENIX 초록 기준 구조: 댓글 하나하나를 **세 축(해외 출처 여부, 도덕·감정 프레이밍, 대상 국가)**으로 분류하는 계층형 모델이고, 판단 근거가 된 **짧은 구절(span)**을 함께 제시합니다. 약 1억 1,200만 건·400만 사용자에서 23,998개 계정을 찾았고, 이 계정들은 해외 서사를 직접 홍보하기보다 **도덕적 비난** 표현을 주로 쓰며 그런 댓글이 더 높은 반응을 얻었습니다.

논문 본문 기준 방법과 이 프로젝트에의 적용:

| 논문 | 이 프로젝트 |
|---|---|
| 댓글 단위 3단계 분류(해외 출처 의심 → 도덕 감정 → 대상) + 근거 구절. GPT-4.1 미세조정 → KcELECTRA 증류 | 평가 표현을 설명용으로만 표시(근거 낱말 밑줄). 점수에는 쓰지 않음 |
| 작성자 특징 24개 → XGBoost (F1 0.94). 중요도: 알려진 계정 팔로우, 자기 복제 비율, 찬양 확률, 해외 의심 확률, 평균 좋아요(높을수록 정상) | 행동 특징만 사용: 자기 복제 비율, 문구 겹침, 다작, 좋아요 감점. 팔로우 대신 답글 주고받기(참고) |
| 활동 시계열 동기화로 검증 (일 단위 상관 0.81 vs 0.65) | 같은 시간대에 함께 쓴 작성자, 영상 간 교차 |
| 바꿔 써도 의미로 탐지 (부록 D) | 같은 주장, 다른 표현 |
| 좋아요 비율로 노출 분석 | YouTube는 싫어요 수가 없어 좋아요 중앙값·상위 10% 비율로 대체 |
| 해외 출처 추정 (작성 지역 메타데이터) | 하지 않음. YouTube에 해당 정보가 없고 오탐 위험이 큼 |
| 윤리: "의심" 표기, 집계 중심, 아이디 가림 | 같은 원칙. `docs/objectivity.md` |
