# 의심 신호 판별 방식과 참고 연구

> 모든 신호는 **판정이 아니라 사람이 검토할 우선순위**입니다. 근거(공통 표현, 작성자 수, 시간대)를 함께 보여 사람이 판단합니다.

## 1. 복붙·템플릿 의심 신호 (`lib/analyze.js` → `clusterSignals`)

1. **문구 임베딩**: 댓글을 정규화(소문자, 문장부호·URL 제거)한 뒤 문자 2·3-gram과 단어를 feature hashing(256차원) → TF-IDF → L2 정규화. 의미가 아니라 **글자가 얼마나 겹치는지**를 잡습니다.
2. **이웃 찾기**: 댓글마다 코사인 유사도 상위 8개 이웃.
3. **묶기**: 유사도가 기준(기본 0.6, 슬라이더) 이상인 이웃끼리 간선을 잇고, 연결된 덩어리를 한 묶음으로 봅니다(union-find).
4. **점수(0~100)**: 묶음마다 아래를 더합니다. 50점 이상이면 그래프에 주황 원으로 표시합니다.

| 근거 | 점수 |
|---|---|
| 묶음 평균 유사도 ≥ 0.75 (거의 같은 문구) / ≥ 0.6 (비슷한 표현) | +35 / +15 |
| 서로 다른 작성자 수 (2명 이상) | +6 × 작성자 수 (최대 30) |
| 같은 작성자가 반복 작성 | +10 |
| 전체 댓글 기간의 10% 이내에 몰려 작성 (3개 이상, 상대시간 근사) | +20 |
| 30자 이상 긴 문장인데도 겹침 | +5 |
| 평균 6자 미만 짧은 반응 ("ㅋㅋ", "와") | 0점 고정 (자연스러운 현상) |

근거로 **공통 표현**(묶음 댓글의 60% 이상이 같이 쓰는 연속 단어 1~8개)을 함께 보여줍니다.

한계: 시간은 "3일 전" 같은 상대시간이라 거칠고, 유명한 밈·유행어도 묶일 수 있으며, 한 영상 안의 정보만 봅니다.

## 2. 작성자 활동 (`authorActivity`)
한 영상에서 3개 이상 쓴 작성자의 댓글 수·비율·답글 수·작성 기간·등장한 주제 묶음 수.

## 3. 참고 연구

**KAIST·막스플랑크 연구팀, USENIX Security 2026** — 네이버 뉴스 댓글 약 1억 1천만 건(2006~2025)을 분석해 해외 연계가 의심되는 계정 약 2만 4천 개를 찾은 설명 가능한 AI 연구 ([AI타임스 기사](https://www.aitimes.kr/news/articleView.html?idxno=41406), [arXiv 2606.22785](https://arxiv.org/pdf/2606.22785)).

USENIX 초록 기준 구조: 댓글 하나하나를 **세 축(해외 출처 여부, 도덕·감정 프레이밍, 대상 국가)**으로 분류하는 계층형 모델이고, 판단 근거가 된 **짧은 구절(span)**을 함께 제시합니다. 약 1억 1,200만 건·400만 사용자에서 23,998개 계정을 찾았고, 이 계정들은 해외 서사를 직접 홍보하기보다 **도덕적 비난** 표현을 주로 쓰며 그런 댓글이 더 높은 반응을 얻었습니다.

기사에 소개된 방법과 이 프로젝트에의 적용:

| 연구의 방법 | 이 프로젝트 |
|---|---|
| 판단 근거가 된 댓글 표현을 보여주는 **설명 가능성**, 최종 판단은 사람 | ✅ 점수 + 근거 + 공통 표현, "판정" 표현 금지 |
| 계정 **활동 빈도·기간** | ✅ 영상 단위로 축소 적용 (활동이 많은 작성자) |
| 의심 계정 간 **활동 상관** (같은 기사에 반복 등장) | ⏳ 저장 없이 하려면 패널 세션 안에서 여러 영상 비교 필요 — 다음 단계 후보 |
| **감정** (도덕적 비난, 맹목적 찬양) 및 **대상** 식별 | ⏳ 의미 임베딩 + 소형 분류/LLM 필요 — 다음 단계 후보 |
| 해외 연계 단서(어휘·맥락) | ✗ 시드 계정 목록 등 외부 데이터 필요, 범위 밖 |

논문 본문(PDF)의 세부 방법(모델 구조, 특징, 성능 수치)은 아직 확인하지 못했습니다. 위 내용은 기사와 USENIX 초록 기준입니다.

다음 단계 아이디어: 의미 임베딩으로 댓글별 어조(도덕적 비난 / 찬양 / 정보·중립)를 프로토타입 문장과의 유사도로 추정하고, 어조별 좋아요 분포를 보여주기.
