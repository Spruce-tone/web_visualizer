# 검증 세트 (객관성 기준 9)

점수 기준·주제 나누기·모델 기본값이 특정 주제나 성향, 특정 영상 하나에 맞춰지지 않았는지 확인하기 위한 영상 모음입니다.

## 어디에 두나
- **실제 댓글은 저장소에 넣지 않습니다.** `fixtures/set/<분류>__<영상ID>.json` 에 로컬로만 둡니다(`.gitignore`).
- 저장소에는 목록만 있습니다: [`validation-set.json`](validation-set.json) (영상 ID, 분류, 수집 날짜, 댓글 수).
- 작성자 이름·채널 ID는 수집하면서 해시(`a_` + 12자리, 소금은 `fixtures/set/.salt`, 로컬)로 바꿉니다. 출신·성향은 추정하지 않습니다.
- 임베딩 캐시: `fixtures/set/emb/<모델>/` (평가 스크립트가 만듦, 로컬).

## 분류와 수
| 분류 | 내용 | 영상 수 |
|---|---|---|
| `news` | 방송사 뉴스 클립 (방송사마다 1개) | 5 |
| `politics-a` | 정치·시사 해설 채널, 한쪽 성향으로 알려진 곳 | 5 |
| `politics-b` | 정치·시사 해설 채널, 반대 성향으로 알려진 곳 | 5 |
| `music` | 뮤직비디오 (소속사마다 1개) | 5 |
| `game` | 게임 | 5 |
| `daily` | 일상·브이로그·먹방 | 5 |

a·b 중 어느 쪽이 어느 성향인지는 의미가 없습니다. 두 쪽을 같은 수로 맞추는 것만 중요합니다.

## 고른 기준 (2026-11-25 세트)
1. 분류마다 이름이 알려진 채널을 여럿 정하고, 채널마다 **최근 한 달 안에 올린 일반 영상(생방송·쇼츠 제외) 중 조회수 1위**를 골랐습니다. 내용을 보고 고르지 않았습니다.
2. 수집한 댓글이 300개 미만이면 빼고 다음 채널로 넘어갔습니다(이번 세트는 모은 55개 중 25개를 뺐습니다. 시사 해설·게임 채널에 댓글이 적은 곳이 많음).
3. 채널을 다 써도 5개가 안 되면 같은 채널의 다음 조회수 영상을 넣었습니다. 이번 세트에서 `politics-a`는 채널 3곳(두 채널이 2개씩), `game`은 채널 4곳(한 채널이 2개)입니다. 나머지 분류는 채널마다 1개입니다.
4. 수집은 확장의 실제 경로(`content/youtube.js` `collectAll`, '고르게 무작위', 답글 포함, 최대 1,000개)로 Edge에서, 영상을 재생하지 않고 했습니다.

## 점검
```bash
npm run evaluate             # 치우침 + 모델 비교 (처음엔 임베딩 계산에 몇 분)
npm run evaluate -- --bias   # 치우침만
```
- 치우침 통과 조건: 오락 분류(music, game, daily)의 복붙 의심 비율 5% 이하, `politics-a`와 `politics-b`의 차이 5%p 이하.
  통과하지 못하면 `lib/weights.js`의 기준을 특정 영상에 맞추지 말고, 자연 반복 규칙(`lib/signals.js`)에 빠진 유형이 있는지부터 봅니다.
- 모델 비교(주제 수, 이름 없는 주제, 겹침, 고차원·지도 실루엣, 섬)는 통과/실패가 아니라 기본값과 상수를 정하는 근거입니다. 결과는 `docs/validation.md`.
- 패널의 "분석 결과를 JSON 파일로 내려받기"로 받은 파일도 `fixtures/set/<분류>__<이름>.json` 으로 넣으면 같이 셉니다.
