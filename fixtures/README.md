# 검증 세트 (객관성 기준 9)

점수 기준이 특정 주제나 성향에 치우치지 않는지 확인하기 위한 영상 모음입니다.
패널에서 영상을 분석한 뒤 **"분석 결과를 JSON 파일로 내려받기"** 로 받은 파일을 이 폴더에 넣습니다.
작성자 이름은 가린 채로 내려받는 것을 권장합니다(기본값).

## 파일 이름: `<분류>__<아무 이름>.json`

| 분류 | 내용 | 권장 수 |
|---|---|---|
| `politics-a` | 정치·시사 채널 (한쪽 성향) | 5 |
| `politics-b` | 정치·시사 채널 (반대 성향) | 5 — a와 같은 수, 비슷한 조회수 |
| `news` | 방송사 뉴스 클립 | 5 |
| `music` | 음악·뮤직비디오 | 5 |
| `game` | 게임 | 5 |
| `daily` | 일상·브이로그·먹방 | 5 |

고르는 원칙: 분류마다 같은 수, 조회수·댓글 수가 비슷한 영상, 한 채널에 몰리지 않게.

## 점검
```bash
npm run evaluate
```
통과 조건: 오락 분류(music, game, daily)의 복붙 의심 비율 5% 이하, `politics-a`와 `politics-b`의 차이 5%p 이하.
통과하지 못하면 `lib/weights.js`의 기준을 특정 영상에 맞추지 말고, 자연 반복 규칙(`lib/signals.js`)에 빠진 유형이 있는지부터 봅니다.
